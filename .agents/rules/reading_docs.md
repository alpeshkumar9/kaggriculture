# Always Consult Documentation First

Whenever working on the Kaggriculture repository:

1. **Mandatory Documentation Read:** Read `overview.md` to understand competition rules, object types, market price formulas, action formats, and observation JSON formats.
2. **Bot Architecture:** Read `python_bot/README.md` for python bot design patterns and test runner instructions.
3. **Web Frontend:** Read `web/README.md` for visualizer app setup.
4. **Verification:** Always run test suites (`python_bot/test_agent.py` or `pytest`) after code modifications to ensure submission validity.
